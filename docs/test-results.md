자동 회비 설정은 지출 없는 모임 생성, 지출 추가·수정·삭제, 회비 지원 제외자, 불균등 분담, 미참가자 환급, 전원 지원 제외, 수동 예산 전환, 서버 저장과 최종 확정을 검사했습니다. 자동 모드에서 기존 수동 금액은 계산 한도로 사용하지 않습니다. 확정된 스냅샷은 추가 계산 없이 유지됩니다.

추가 검사에서 발견해 수정한 문제는 다음과 같습니다.

- 과거 생성자가 viewer로 변경되어도 공유 설정을 수정할 수 있던 권한 누락: user/admin 역할 요구로 수정.
- 취소한 임시 저장이 남은 타이머나 화면 종료 때 되살아나는 문제: 저장 예약도 함께 취소.
- 계정 변경 후 이전 계정의 임시 저장 안내가 남는 문제: 계정별 상태와 저장 범위 분리.
- 정상적인 `127.0.0.1` 요청이 NextURL의 localhost 정규화로 CSRF 검사에서 차단되는 문제: 실제 요청 Host를 검증하고 출처 일치를 비교. 다른 출처와 잘못된 Host 차단은 유지.
